# API de productos

Backend PHP y MySQL del practico de Full Stack.

## Instalacion
1. Tener PHP con PDO, pdo_mysql y mbstring.
2. Ejecutar database/estructura.sql en MySQL.
3. Copiar conexion.ejemplo.php como conexion.php si no existe.
4. Configurar en conexion.php el usuario y la contraseña de MySQL.
5. Desde esta carpeta ejecutar: php -S localhost:3000

Frontend permitido por CORS: http://127.0.0.1:5501
La base comienza vacia. Crear productos desde el frontend.
